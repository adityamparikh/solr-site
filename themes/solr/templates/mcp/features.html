MCP Tools

Tool Reference

Each tool is callable by any MCP-compatible AI client. The AI translates natural language into the right tool calls automatically.

Search

ToolDescription
search Full-text search with filtering, faceting, sorting, and pagination. Accepts query strings, filter queries, facet fields, sort clauses, start offset, and row count.

Indexing

ToolDescription
index-json-documents Index documents from a JSON array string. Handles batch processing (1,000 per batch), field name sanitization, and automatic commits.
index-csv-documents Index documents from a CSV string. First row is used as headers. Same batch processing and field normalization.
index-xml-documents Index documents from a Solr XML string (<add><doc>...).

Collections

ToolDescription
list-collections List all available Solr collections in the cluster.
get-collection-stats Comprehensive metrics: index stats, query performance, cache hit ratios, handler throughput.
check-health Health check returning status, document count, and responsiveness.
create-collection Create a new collection with configurable shards, replicas, and configset. Defaults: _default configset, 1 shard, 1 replica.

Schema

ToolDescription
get-schema Retrieve the complete schema definition: field definitions, field types, dynamic fields, copy fields, unique key, and schema attributes.
add-fields Add one or more fields to a collection's schema atomically. Each field is a map matching Solr's add-field JSON shape (required name and type, plus optional stored, indexed, docValues, multiValued, etc.). Additive only — existing fields cannot be modified.
add-field-types Add one or more field types atomically. Each map matches Solr's add-field-type shape with required name and class, plus optional analyzer (or separate indexAnalyzer + queryAnalyzer). Supports custom analyzer chains, solr.DenseVectorField for semantic search, autocomplete patterns, and more.
MCP Prompts

Workflow Templates

MCP Prompts are reusable workflow templates that the AI client surfaces as slash-command-style entry points. Each prompt points the LLM at the right tools in the right order and embeds user-supplied arguments.

PromptArgumentsDescription
explore-collections — Read-only walkthrough: list collections, inspect their schemas, check health. Use when investigating what's available.
setup-collection name, purpose (optional) Create a new collection with sensible defaults (configset _default, 1 shard, 1 replica), then suggest schema fields based on the stated purpose.
view-schema collection Read-only schema introspection. Fetches the schema and summarises field definitions, dynamic fields, and copy fields.
design-schema collection, datasetDescription, sampleDocument (optional) Propose and apply schema fields/field types for a described dataset, leveraging add-fields and add-field-types.
index-data collection, format (json/csv/xml), sample (optional) Walks through indexing documents in the chosen format, branching to the right index-*-documents tool.
search-collection collection, question Translate a natural-language question into a Solr query, including filter queries, faceting, and pagination as appropriate.
MCP Resources

Read-Only Data

MCP Resources provide data that clients can access directly without calling a tool. The schema resource supports autocompletion for collection names.

Resource URIDescription
solr://collections List of all Solr collections available in the cluster.
solr://{collection}/schema Schema definition for a specific collection. Supports autocompletion—MCP clients can query for available collection names.
MCP Completions

Argument Autocompletion

MCP Completions let clients query the server for valid values when filling in resource URI placeholders. The Solr MCP server exposes one completion today, with more planned as new templated resources are introduced.

Completion TargetDescription
solr://{collection}/schema → {collection} Returns the live list of collection names from Solr so MCP clients can offer them as completion candidates when a user is composing a schema resource URI.
